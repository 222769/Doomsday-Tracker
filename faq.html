Frequently asked questions

What is "Doomsday"?

It's the target date the countdown on the checklist page counts down to — the release everything on this list is meant to prepare you for. Change the date in app.js if you're reusing this tracker for a different release.

Where is my progress saved?

In your browser's local storage, on this device only, by default. Clearing your browser data, using a different browser, or switching devices will reset the checklist — unless you use a sync code (below).

How does syncing across devices work?

Tap "Get a sync code" on the checklist page and you'll get a short code like K7XQ-9F2M. Enter that same code on another device (or send it to someone else) and both devices share one checklist from then on — no account, no username or password. Anyone with the code can view and check off items, so treat it like a share link. This feature only appears once the site's owner has configured it; see SYNC_SETUP.md in the repo.

What's the difference between release order and timeline order?

Release order is the order titles actually came out. Timeline order is the in-universe chronological order. Use the toggle above the checklist to switch between them at any time.

Can I check off individual episodes?

Yes. Tap "Show episodes" under any show to reveal its episode list, each with its own checkbox — pace yourself episode by episode instead of all at once. The show's own checkbox becomes a shortcut: check it to mark every episode watched, uncheck it to clear them all. A dash instead of a checkmark means it's partway done.

What does a "stop point" mean?

A few shows only have a portion of their run listed as required viewing. When an item has a stop point, it's shown right under the title — for example, "watch through S1E4 only."

Can I use this offline?

Yes. Watch Tracker is an installable app (PWA). After your first visit, the app shell is cached so it keeps working without a connection, and your checked-off progress is read from local storage either way.

How do I add my own list?

The whole checklist comes from a single data.js file. If you're comfortable editing a bit of JavaScript, you can swap in your own titles, order numbers, and runtimes.

Is this affiliated with Marvel or Disney?

No. Watch Tracker is an independent, fan-made project, not affiliated with, endorsed by, or sponsored by Marvel Studios, Disney, or any other rights holder. It's just a personal watch-order tool built around publicly available release information.
